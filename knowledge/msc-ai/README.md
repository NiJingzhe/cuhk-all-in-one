# MSc AI — 学科知识路由

存放 MSc in Artificial Intelligence 项目专属知识（其他学科请另建 `<subject>/` 目录）。内容对 Common 路由不可见，反之 Common 对本学科可见。

## 本路由的文件

| 文件 | 说明 |
|---|---|
| `programme.md` | 项目信息与联系方式（官网、项目办 mscai@cuhk.edu.hk、何善衡楼 606 室）— 已核验 |
| `search-playbook.md` | 学科级信息源手册（项目官网、CUSIS、Blackboard、评价站）。学科专属的查询方法放这里，全校通用方法在 Common 的 search-playbook |
| `lesson/` | **课程文件**（每门课一个）：上课日、地点（引用 place/ 到达指南）、教授、考核。学期固定信息 bake，作业/通知实时查 Blackboard |

## 待填充

## 新增文档

1. 按 `../FORMAT.md` 模板写 `<主题>.md`（没有 URL 来源的事实不允许入库）。
2. 在上面索引表加一行。
3. event 类文档（迎新、讲座、deadline）`stable_until` 填事件结束日，过期即失效，不必删除。

## 与 Common 的分工

- "工程楼怎么走" → 地点到达指南在 `../common/place/`（何善衡工程楼已有），坐什么车指向 `../common/bus/`，不重复抄班次。
- 全校通用查询方法在 `../common/search-playbook.md`；**学科专属信息源只进本路由的 `search-playbook.md`**——Common 手册不收学科条目，反之亦然。
