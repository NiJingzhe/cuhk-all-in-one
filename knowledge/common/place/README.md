## Place 文档格式

在 FORMAT.md 通用格式基础上（`kind: place`），place 文档正文必须包含：

1. **地点识别**：中英文名、缩写、常见别名（课表上的别名讲堂/礼堂名尤其重要）。
2. **到达方式总表**：每个方案一行——坐什么线、在哪上、在哪下、步行距离/时间。**线路班次一律用引用**指向 `../bus/` 的具体段落（如 `[[../bus/routes-shuttle#1 — Main（主校园环回）]]`），不得复制时刻数字。
3. **分步详解**：下车后的步行路径按步骤写，配 `assets/` 实景图。
4. **来源**：社区攻略（小红书笔记等）逐条给 URL、作者、发布日期；与官方数据交叉核验过的点标注出来。

## 扩充方式

- 每个新地点一个 `<英文名>.md`，加进上面索引。
- 搜攻略优先小红书（方法见 `../search-playbook.md` 的"小红书"条目）；官方渠道查不到的"在哪下车怎么走"正是社区攻略的价值所在。
- 已知优质来源：小红书用户 **咖啡的刺客** 的《cuhk校巴直达教学楼》系列（0 总纲 / 01 蒙民伟工程楼 / 02 何善衡工程楼 / 04 富尔敦楼 / 05 蒙民伟楼 / 06 李兆基楼）及《校巴直达食堂》系列（和声、大膳堂/面膳坊/范克廉、伍宜孙）——补齐新地点时优先从该系列取材。
- 社区路线网站：cuhk-shortcut-finder.lovable.app（步行捷径图解）。
