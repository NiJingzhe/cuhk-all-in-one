# Common — 全校公共知识路由

存放对**所有 CUHK 学生**都适用的知识（不区分学科），包括事实数据、地点指南和**查信息的方法**。索引如下：

| 主题 | 位置 | 说明 |
|---|---|---|
| 校园巴士（校巴/上下课班车/收费小巴） | `bus/` | 线路、班次、站点、路线规划 |
| 地点到达指南（某栋楼怎么去） | `place/` | 按地点沉淀"坐哪条线、哪站下、怎么走"，用引用指向 bus 文档，不复制班次 |
| 官方信息搜索手册 | `search-playbook.md` | 单文件方法文档：去哪查官方信息、小红书抓取方法、未核验线索清单。知识库没有现成答案时先来这里 |

## 新增主题

1. 事实/地点类建子目录 `common/<topic>/`（结构参照 `bus/`）；纯方法类可以像 `search-playbook.md` 一样放单文件，同样要带 FORMAT.md 规定的 frontmatter。
2. 把新主题加进上面索引表。
3. 同时检查 `SKILL.md` 的路由表是否需要加一行。
