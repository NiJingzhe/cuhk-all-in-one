# 校园巴士知识索引

CUHK 校园交通分三个体系，先分清用户问的是哪一类，再读对应文档：

| 体系 | 特点 | 文档 |
|---|---|---|
| **Campus Shuttle 校巴** | 免费，仅限师生，周一至六（公众假期停开） | `routes-shuttle.md`（1/2/2S/3/4/8/N/H） |
| **Meet-Class 上下课班车** | 免费，**仅教学日**（teaching days）开行，主要衔接崇基与各书院 | `routes-meetclass.md`（5/6A/6B/7） |
| **PSLB 收费小巴** | $5.5，**公众可乘**，每日开行，往返大学站与宿舍区 | `routes-pslb.md`（Up/Down） |

## 按问题类型路由

| 用户问什么 | 读 |
|---|---|
| 有哪些线、几点开几点收、票价、能不能坐（资格/行李） | `overview.md` |
| 某条校巴线的站点顺序 / 班次 | `routes-shuttle.md` |
| 上下课班车（5/6A/6B/7） | `routes-meetclass.md` |
| 往返大学站（港铁）的小巴、$ 票价 | `routes-pslb.md` |
| **A 地 → B 地怎么走 / 在哪上车下车 / 末班车赶不赶得上** | `planning.md`（规划方法论 + 典型场景），再回查对应线路文档 |
| **具体某栋楼怎么去**（如何善衡工程楼） | `../place/README.md` 的地点索引——那里有逐楼的"哪站下+怎么走"，本目录只管线路本身 |
| 线路时刻疑似变了 / 让你确认班次 | 按 `../search-playbook.md` 的"校园交通"条目复核 |

## 关键背景（回答前先记住）

- "教学日" ≠ 周一至周五：周六可能教学，假期/Reading week 不算。上下课班车只看教学日。
- 校巴线路 2026-09-01 大改过（1B 取消、新增 2S、2/7/8 班次调整），网上旧攻略不可信。
