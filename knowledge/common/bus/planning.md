# 校巴路线规划

## 方法论（按步骤构造方案）

1. **定位端点**：把出发地/目的地映射到官方站名（对照表见 `overview.md`）。楼宇说不清时让用户给课程代码或书院名，再转站名。
2. **选候选线**：在 routes-*.md 的站序里找同时包含两端点的线路，**且顺序同向**。站名带 (Upward)/(Downward) 是不同位置的站台，方向标错会坐反。
3. **校时刻**：发车分钟 + 服务日。特别注意三类坑：教学日线（5/6A/6B/7）周末与假期停开；N/H 是夜间/假日专用；#:45、:00 等特殊停靠规则（见 routes-shuttle.md 各线"特殊"栏）。
4. **不直达就换乘**：优先在枢纽站换乘（见下表），其次建议步行（山地校园，能不换就不换）。
5. **输出方案**：说清"几点几分发车 → 在哪上 → 在哪下 → 下车后往哪走 → 备选方案 + 末班车风险"。回答末尾附核验来源。

## 换乘枢纽

| 枢纽 | 意义 |
|---|---|
| Univ. Station（大学站） | 一切的起点：校巴 1/2/2S/N/H 总站 + PSLB Up 总站 |
| Station Piazza（站前广场） | 2 总站、3/6A/6B/7/8 沿途，近大学站步行可达 |
| S.H. Ho College / Univ. Admin. Bldg. | 主校园轴带东侧，几乎所有下行线必经 |
| New Asia College / United College | 书院换乘（2/2S/4/8/上下课班车交汇） |

## 典型场景（已按 2026-09-07 数据验证）

### 大学站 ↔ 各处（新生最常问）

- **→ 康本国际学术园 (Y.I.A.P.)**：出站即到，无需坐车。⚠️经验推断：大学站与康本园有天桥/坡道直连。
- **→ 主校园（图书馆/邵逸夫堂/行政楼）**：坐校巴 1（:10/:25/:40/:55 发车）到 Sir Run Run Shaw Hall 或 Univ. Admin. Bldg.；非师生/拖大行李则坐 PSLB Up 到 University Library / Art Museum。
- **→ 何善衡工程学大楼**（工程学院、MSc AI 活动常在此）：PSLB Up 到 Academic Bldg. No.1 下车。⚠️经验推断：工程楼群（何善衡/何添楼）在本部轴带旁，下车步行几分钟；下山方向 PSLB Down 有 Ho Sin-Hang Engineering Bldg. 专站。
- **→ 崇基（上课）**：教学日白天坐 5 号线不现实（它从崇基发车上山）；从大学站步行上山，或校巴 8（非教学日改停崇基教学大楼）。⚠️经验推断：大学站 → 崇基教学大楼步行约 10–15 分钟上坡。
- **→ PGH 1（研究生宿舍一座）**：校巴 2S 直达（:00/:30 发车，站前广场上车）；夜间 N 线官方仅保证 :00 班停 PGH 1。
- **→ 十、十一座宿舍**：PSLB Up 终点即到；校巴 4/8/N/H 经 Residence No. 15 后步行。

### 各书院 → 大学站（赶港铁）

- 逸夫书院：教学日坐 7 号线（:00/:18，下山直达崇基教学大楼/站前广场）；其他时段坐 3 号线到 Station Piazza。
- 新亚/联合：6B（教学日 12:20 后）、6A/7，或校巴 2/4/8 到 S.H. Ho College 附近换 1 号线/步行下山。
- 陈震夏/十五座一带：PSLB Down 早班（07:00–08:15 每 15 分钟）最直接；白天用 3/4 号校巴。

### 时段风险表

| 场景 | 事实 | 给用户的提示 |
|---|---|---|
| 周六白天 | Meet-Class 5/6A/7 有周六班（至 13:10–13:26 止），6B 无 | 周六下午起只剩校巴 |
| 周日/公众假期 | 校巴仅 H 线（08:20–23:20）+ PSLB 全日 | 别等 1/2/3/4/8，它们停开 |
| 晚上 19:00 后 | 校巴仅 N 线（末班 23:30 发车） | 只有 :00 班保证停 PGH 1 |
| 教学日白天上山 | 5 号线 :18/:22/:26 三连发，密度最高 | 优先 5 号，其次校巴 1/2 |
| 拖行李 | PSLB 禁大件；校巴 NS 班限 1 件 22″×14″×9″ | 大行李打车的士或走 S 班规则内尺寸 |
| 8 号线非教学日 | 不停 Univ. Station，改停 Station Piazza + 崇基教学大楼 | 到大学站别坐 8，坐 1/2 或 PSLB |

## 经验推断（非官方，回答时需声明）

- ⚠️ 山地校园，同一书院的 Upward/Downward 站台可能相距数百米，按站序方向在标记的一侧等车。
- ⚠️ 校巴不报站，上车前告诉司机目的地或盯地图；下车按铃。
- ⚠️ 高峰期（上下课时段）校巴会满员跳站，NS 班尤其严格，赶时间多留一班余量。
- ⚠️ "发车分钟"指始发站发车，到中途站的时间要加 2–10 分钟（视距离），赶具体时刻的活动请提前一班车。
