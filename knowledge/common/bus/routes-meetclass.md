# 上下课班车（免费，仅限师生，仅教学日）

为上下课高峰设计：把学生从**崇基教学大楼 / 崇基学院**（近大学站）送上山，或从各书院送回山下。**只在 teaching days 开**——周六有课的日子也开（见下），Reading week/假期不开。

| 线 | 方向 | 时段（周一至五） | 时段（周六） | 发车(mins) |
|---|---|---|---|---|
| 5 | 崇基教學樓 → 上山 | 09:18–17:26 | 09:18–13:26 | :18/:22/:26 |
| 6A | 陳震夏一带 → 崇基教學樓（下山） | 09:10–17:10 | 09:10–13:10 | :10 |
| 6B | 新亞 → 崇基教學樓（下山） | 12:20–17:20 | 不开 | :20 |
| 7 | 逸夫 → 崇基教學樓（下山） | 08:18–17:18 | 08:18–13:18 | :00/:18 |

> 核验：2026-09-07，来源：各线路页 Service Hours 块（周一至五、周六两个时段块均为官方原文）

## 5 — Upward（上山）

- 站序：**Chung Chi Teaching Bldg.** → Univ. Sports Centre → Sir Run Run Shaw Hall → Fung King Hey Bldg. → United College (Upward) → New Asia College → Wu Yee Sun College (Upward) → Shaw College (Upward) → **CW Chu College (Downward)**
- 三个发车分钟连发（:18/:22/:26），高峰密度全校最高。

## 6A — Downward via Chan Chun Ha（下山，经陈震夏）

- 站序：**CW Chu College (Downward)** → U.C. Staff Residence → Chan Chun Ha Hostel → Wu Yee Sun College (Downward) → New Asia College → United College (Downward) → Univ. Admin. Bldg. → S.H. Ho College → Station Piazza → **Chung Chi Teaching Bldg.**

## 6B — Downward via NA/UC（下山，经新亚/联合）

- 站序：**New Asia College** → United College (Downward) → Univ. Admin. Bldg. → S.H. Ho College → Station Piazza → **Chung Chi Teaching Bldg.**
- 只在周一至五中午后开行。

## 7 — Downward via Shaw（下山，经逸夫）

- 站序：**Shaw College (Downward)** → Wu Yee Sun College (Downward) → New Asia College → United College (Downward) → Univ. Admin. Bldg. → S.H. Ho College → Station Piazza → **Chung Chi Teaching Bldg.**

## 什么时候用上下课班车 vs 校巴

- 教学日白天从山下上山：5 号线密度最高（每 4 分钟一班发车）。
- 6A/6B/7 的终点都是崇基教学大楼 + 路经 Station Piazza——下课回大学站赶车，这三条比等校巴更直接。
- 非教学日（假期/周末不上课）它们全停，只能靠校巴 1/2/3/4/8 与 PSLB 小巴。
